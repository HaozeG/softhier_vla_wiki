# Model families and named models

## Summary
Kinds of policy model (single-task imitation policies, VLAs, dual-system VLAs, world models, WAMs) and one-line identities of the named models the notes compare: organisation and design family only; sizes and speeds are in the model notes and in `knowledge/`. All terms are standard (scope field). The [catalog of model notes](../resources/models/_overview.md) lists every model source.

## Terms
| Term                                        | Meaning                                                                                                                                                                                                                                                                                                                                                           | Scope | Defined in                                                                    |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- | ----------------------------------------------------------------------------- |
| dual-system VLA                             | A VLA built from two separate networks, a large System two and a small System one, that run at different rates and are joined by a latent. Sources differ on whether System one must take its own camera images: OpenHelix requires it, while GR00T N1's authors use the term for a model whose action module sees images only through the vision-language model. | field | [dual-system VLA](../knowledge/dual-system-vla.md)                            |
| System 1, System 2 (small brain, big brain) | In a dual-system VLA, System two is the large, slow vision-language model that reads the scene and instruction, and System one is the small, fast policy that produces the actions. Big brain and small brain are informal names for the same two parts.                                                                                                          | field | [dual-system VLA](../knowledge/dual-system-vla.md)                            |
| latent interface                            | The vector or tokens that System two passes to System one, for example a learned action token's embedding or hidden states from the language model. It is what the small policy is conditioned on between System two calls.                                                                                                                                       | field | [dual-system VLA](../knowledge/dual-system-vla.md)                            |
| world model                                 | A model of how the observation changes: given the current observation, action and language, it predicts the next observation. It need not choose the action.                                                                                                                                                                                                      | field | [WAM overview](../knowledge/wam-overview.md)                                  |
| WAM (world action model)                    | A model in which a predicted future observation helps produce the action, score it or train the action path inside one model. A VLA acts from the present observation only. Some sources use the name only for the predict-then-act case.                                                                                                                         | field | [WAM overview](../knowledge/wam-overview.md)                                  |
| ACT (Action Chunking with Transformers)     | A single-task imitation policy from Stanford and partners: a transformer trained as a conditional VAE that outputs a chunk of joint targets from camera images and joint positions, with temporal ensembling. Introduced with the ALOHA set-up.                                                                                                                   | field | [ACT](../resources/models/act-aloha.md)                                       |
| Diffusion Policy                            | A single-task imitation policy from Columbia and partners that generates an action sequence by denoising diffusion conditioned on the observations, executed with a receding horizon.                                                                                                                                                                             | field | [Diffusion Policy](../resources/models/diffusion-policy.md)                   |
| RT-2                                        | Google DeepMind's vision-language-action model: a large vision-language model fine-tuned on web data and robot data, with actions written as text tokens. The paper that named the VLA.                                                                                                                                                                           | field | [rt-2](../resources/models/rt-2.md)                                           |
| OpenVLA                                     | An open VLA from Stanford, Berkeley and partners, built on the Prismatic vision-language model and trained to write discretized action tokens.                                                                                                                                                                                                                    | field | [openvla](../resources/models/openvla.md)                                     |
| OpenVLA-OFT                                 | A fine-tuning recipe for OpenVLA from Stanford: parallel decoding, action chunking, continuous actions and an L1 loss.                                                                                                                                                                                                                                            | field | [openvla-oft](../resources/models/openvla-oft.md)                             |
| Octo                                        | An open generalist robot policy from Berkeley and partners: a small transformer with a diffusion action head, not built on a vision-language model.                                                                                                                                                                                                               | field | [octo](../resources/models/octo.md)                                           |
| π0 (pi0)                                    | Physical Intelligence's flow-matching VLA: a vision-language model with a separate action expert that generates continuous action chunks.                                                                                                                                                                                                                         | field | [pi0](../resources/models/pi0.md)                                             |
| π0.5 (pi0.5)                                | The successor of π0 from Physical Intelligence: co-trained on heterogeneous data, it first writes a text subtask and then low-level actions, and adds a flow-matching action expert after pretraining with discrete FAST tokens.                                                                                                                                  | field | [pi05](../resources/models/pi05.md)                                           |
| GR00T N1                                    | NVIDIA's open VLA for humanoid robots, which its authors call dual-system: a vision-language model (system two) plus a diffusion transformer trained with flow matching (system one) that takes robot state and the vision-language features but no images of its own. OpenHelix's narrower definition excludes it.                                               | field | [gr00t-n1](../resources/models/gr00t-n1.md)                                   |
| Helix                                       | Figure's VLA for humanoid upper-body control: a slow vision-language model plus a fast visuomotor policy, running on the robot's embedded GPUs; described only on a company blog page.                                                                                                                                                                            | field | [figure-helix](../resources/models/figure-helix.md)                           |
| SmolVLA                                     | Hugging Face's small open VLA: a truncated SmolVLM backbone with a flow-matching action expert, plus an asynchronous inference stack.                                                                                                                                                                                                                             | field | [smolvla](../resources/models/smolvla.md)                                     |
| TinyVLA                                     | A small, fast VLA from ECNU and partners: a small Pythia-based vision-language model fine-tuned with LoRA and a diffusion policy head, without large-scale robot pretraining.                                                                                                                                                                                     | field | [tinyvla](../resources/models/tinyvla.md)                                     |
| Gemini Robotics On-Device                   | Google DeepMind's VLA announced for running locally on robot devices without a data network; the announcement gives almost no technical detail.                                                                                                                                                                                                                   | field | [gemini-robotics-on-device](../resources/models/gemini-robotics-on-device.md) |
