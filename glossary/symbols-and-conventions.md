# Symbols and conventions

## Summary
The symbols that recur across the notes and where the wiki uses one letter or one unit for two things (N, E, L, Hz, Δ). Every row is a convention and is loaded into project sessions.

## Terms
| Term           | Meaning                                                                                                                                                                                                                                                                             | Scope      | Defined in                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ----------------------------------------------------------------------------------------------------- |
| H, n, K        | Actions per chunk: the same quantity under different names in different sources.                                                                                                                                                                                                    | convention | [action representation and chunking](../knowledge/action-representation-and-chunking.md)              |
| T              | Number of flow steps per chunk.                                                                                                                                                                                                                                                     | convention | [one VLA call](../knowledge/one-vla-call.md)                                                          |
| l (ℓ)          | Latency of one model call, a time. Some sources write it with a script l.                                                                                                                                                                                                           | convention | [one VLA call](../knowledge/one-vla-call.md)                                                          |
| dt (Δt)        | Control period.                                                                                                                                                                                                                                                                     | convention | [one VLA call](../knowledge/one-vla-call.md)                                                          |
| L              | LLM layer count in the model notes. Jetson-PI uses L for the number of actions executed per chunk, which the serving note writes s.                                                                                                                                                 | convention | [VLA architecture overview](../knowledge/vla-architecture-overview.md)                                |
| N              | Number of LLM layers used (SmolVLA keeps the first half). In the EfficientVLA part of flow-step reduction, N is instead the number of flow steps between feature recomputations. Check the note.                                                                                    | convention | [VLA architecture overview](../knowledge/vla-architecture-overview.md)                                |
| xN in diagrams | A loop that repeats N times.                                                                                                                                                                                                                                                        | convention | [wiki-design decision 0011](../wiki-design/decisions/0011-diagrams-show-parts-data-and-repetition.md) |
| Hz             | Events per second. For a model that returns chunks it matters what is counted: model calls per second, control steps per second, or actions per second (the OpenVLA-OFT tables count actions per second, so a call that returns a chunk counts once per action). A note says which. | convention | [action representation and chunking](../knowledge/action-representation-and-chunking.md)              |
| Δ (versus Δt)  | Δt is the control period, a time. Δ without t is Jetson-PI's latency counted in control steps, written d in the serving note; it is not a time.                                                                                                                                     | convention | [one VLA call](../knowledge/one-vla-call.md)                                                          |
