# Symbols and conventions

## Summary
The symbols that recur across the notes and where the wiki uses one letter or one unit for two things (N, E, L, Hz, Δ). Every row is a convention and is loaded into project sessions.

## Terms
| Term                         | Meaning                                                                                                                                                                                                                                                                                                                                                                                                            | Scope      | Defined in                                                                                                                                                                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| H, n, K                      | Actions per chunk: the same quantity under different names in different sources.                                                                                                                                                                                                                                                                                                                                   | convention | [action representation and chunking](../knowledge/action-representation-and-chunking.md)                                                                                                                                                               |
| T                            | Number of flow steps per chunk.                                                                                                                                                                                                                                                                                                                                                                                    | convention | [flow-step reduction](../knowledge/flow-step-reduction.md)                                                                                                                                                                                             |
| l (ℓ)                        | Latency of one model call.                                                                                                                                                                                                                                                                                                                                                                                         | convention | [serving methods](../knowledge/serving-methods.md)                                                                                                                                                                                                     |
| dt (Δt)                      | Control period.                                                                                                                                                                                                                                                                                                                                                                                                    | convention | [serving methods](../knowledge/serving-methods.md)                                                                                                                                                                                                     |
| g                            | Fraction of a chunk left in the queue at which the next call is requested.                                                                                                                                                                                                                                                                                                                                         | convention | [serving methods](../knowledge/serving-methods.md)                                                                                                                                                                                                     |
| L                            | LLM layer count in model notes; in the Jetson-PI part of the serving note, actions executed per chunk. Check the note.                                                                                                                                                                                                                                                                                             | convention | [serving methods](../knowledge/serving-methods.md)                                                                                                                                                                                                     |
| N                            | Number of LLM layers used (SmolVLA keeps the first half). In the EfficientVLA part of flow-step reduction, N is instead the number of flow steps between feature recomputations. Check the note.                                                                                                                                                                                                                   | convention | [SmolVLA](../knowledge/smolvla.md), [flow-step reduction](../knowledge/flow-step-reduction.md)                                                                                                                                                         |
| xN in diagrams               | A loop that repeats N times.                                                                                                                                                                                                                                                                                                                                                                                       | convention | [wiki-design decision 0011](../wiki-design/decisions/0011-diagrams-show-parts-data-and-repetition.md)                                                                                                                                                  |
| Hz                           | Events per second. For a model that returns chunks it matters what is counted: model calls per second, control steps per second, or actions per second (the OpenVLA-OFT tables count actions per second, so a call that returns a chunk counts once per action). A note says which.                                                                                                                                | convention | [action representation and chunking](../knowledge/action-representation-and-chunking.md)                                                                                                                                                               |
| Δ (versus Δt)                | Δt is the control period, a time. Δ without t, in the Jetson-PI part of the serving note, is the latency counted in control steps, not a time.                                                                                                                                                                                                                                                                     | convention | [serving methods](../knowledge/serving-methods.md)                                                                                                                                                                                                     |
| D, d, f_c, f_eff, P, E, E[l] | D: number of dimensions of one action. f_c: the controller rate, and d: the call latency counted in control steps, rounded up. f_eff: the action-supply rate, the chunk length divided by the call latency, not a feedback rate. P: cost of the once-per-call prefix part of a call, and E: cost of one expert step. E[l]: the expected latency. E means a step cost, except in E[l], where it is the expectation. | convention | [action representation and chunking](../knowledge/action-representation-and-chunking.md), [serving methods](../knowledge/serving-methods.md), [flow-step reduction](../knowledge/flow-step-reduction.md), [vla.simd](../resources/serving/vla-simd.md) |
