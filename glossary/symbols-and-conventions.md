# Symbols and conventions

## Summary
The symbols that recur across the notes and where the wiki uses one letter or one unit for two things (N, L, Hz). Every row is a convention and is loaded into project sessions.

## Terms
| Term           | Meaning                                                                                                                                                                                                                                                                                                                                                              | Scope      | Defined in                                                                                            |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ----------------------------------------------------------------------------------------------------- |
| H, n, K        | Actions per chunk: the same quantity under different names in different sources. K has a second use: Diffusion Policy writes K for its number of denoising steps, and a note says which is meant. Diffusion Policy also writes its own horizons as T_o (observations read), T_p (actions predicted) and T_a (actions executed), unrelated to T, the flow-step count. | convention | [action representation and chunking](../knowledge/action-representation-and-chunking.md)              |
| L              | The full LLM layer count of a model, as given in the model notes.                                                                                                                                                                                                                                                                                                    | convention | [VLA architecture overview](../knowledge/vla-architecture-overview.md)                                |
| N              | The number of LLM layers a model actually runs, when it keeps only some of the L layers (SmolVLA keeps the first half).                                                                                                                                                                                                                                              | convention | [VLA architecture overview](../knowledge/vla-architecture-overview.md)                                |
| Hz             | Events per second. For a model that returns chunks it matters what is counted: model calls per second, control steps per second, or actions per second (the OpenVLA-OFT tables count actions per second, so a call that returns a chunk counts once per action). A note says which.                                                                                  | convention | [action representation and chunking](../knowledge/action-representation-and-chunking.md)              |
| xN in diagrams | A loop that repeats N times.                                                                                                                                                                                                                                                                                                                                         | convention | [wiki-design decision 0011](../wiki-design/decisions/0011-diagrams-show-parts-data-and-repetition.md) |
