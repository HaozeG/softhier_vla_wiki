# Project terms

## Summary
Terms that SoftHier-VLA defines in its own design decisions, such as the name of a mapping or a schedule. Their names are listed at the start of every project session, and they override general knowledge. A decision that introduces or redefines a term lists it in `defines:` and adds its row here in the same commit. The row SoftHier comes from the project README (see the SoftHier SDK page) and the level-naming row from the maintainer; other rows come from decisions.

## Level naming: how sources use the System words
The project row above replaces neither the field rows [System 1, System 2](model-families.md) nor the convention row [System 0](model-families.md); it fixes the project's own words so that a reader does not have to guess which usage is meant. Recent papers use the System words in three ways (listed by the maintainer; only the sources with a wiki note were checked here, the others are **not ingested**):

| Usage                                                              | Examples                                                                                                                                                                                |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| (A) Inside one model: VLM = System 2, action head = System 1       | [GR00T N1](../resources/models/gr00t-n1.md); not ingested: Psi0 ([arXiv 2603.12263](https://arxiv.org/abs/2603.12263)), VLA-Perf ([arXiv 2602.18397](https://arxiv.org/abs/2602.18397)) |
| (B) The whole VLA = System 1, under a separate reasoner (System 2) | not ingested: Hi Robot ([arXiv 2502.19417](https://arxiv.org/abs/2502.19417)), KinetIQ ([thehumanoid.ai](https://thehumanoid.ai/ai))                                                    |
| (C) The motor controller = System 1                                | not ingested: LeVERB ([arXiv 2506.13751](https://arxiv.org/abs/2506.13751))                                                                                                             |

System 0 for a fast whole-body controller below these levels: TANGO (see [dual-system VLA](../knowledge/dual-system-vla.md)); not ingested: Helix 02 ([figure.ai](https://figure.ai/news/helix-02)), Psi0, KinetIQ. Their controller sizes and rates are findings and belong in source notes once these papers are ingested. The project's S0 is the same layer, placed on the SoftHier chip.
