# Project terms

## Summary
Terms that SoftHier-VLA defines in its own design decisions, such as the name of a mapping or a schedule. Their names are listed at the start of every project session, and they override general knowledge. A decision that introduces or redefines a term lists it in `defines:` and adds its row here in the same commit. The one row so far, SoftHier, comes from the project README (see the SoftHier SDK page), not from a decision.
