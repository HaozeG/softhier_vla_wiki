# Devices and toolchains

## Summary
The chips, memory types, kernel and graph words, toolchains, robot buses and chip terms the notes use. All terms are standard (scope field); the SoftHier chip terms come from the project README.

## Terms
| Term                            | Meaning                                                                                                                                                                                                                                                                                                   | Scope | Defined in                                                           |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- | -------------------------------------------------------------------- |
| LPDDR, DRAM                     | DRAM is the main memory outside the chip, where a model's weights live; LPDDR is the low-power kind used in edge chips.                                                                                                                                                                                   | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| kernel, kernel fusion           | A kernel is one GPU operation launch; fusion combines several into one to cut overhead.                                                                                                                                                                                                                   | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| tensor core versus CUDA core    | On NVIDIA GPUs, tensor cores are units specialised for small matrix multiplies at low precision, and CUDA cores are the general arithmetic units. A kernel that uses tensor cores can be faster on the same data. Standard gloss.                                                                         | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| eager versus compiled execution | Eager execution runs a model operation by operation as written and pays overhead for each; compiled execution first fuses and records the operations so that overhead is smaller.                                                                                                                         | field | [SmolVLA](../knowledge/smolvla.md)                                   |
| GEMM                            | Matrix-matrix multiply, the main operation of a model's layers.                                                                                                                                                                                                                                           | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| tile                            | A block handled as a unit. Image tile: one crop of an image that is cut into several. GEMM tile: the block of the result matrix that one compute unit works on; tile quantization is the loss when the tiles do not divide evenly across the units. SoftHier tile: one tile of a tile-based many-PE chip. | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| SM                              | Streaming multiprocessor: one compute unit of an NVIDIA GPU.                                                                                                                                                                                                                                              | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| PE (processing element)         | One small compute unit of a many-PE chip.                                                                                                                                                                                                                                                                 | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| SRAM                            | Static random-access memory: fast memory on the chip itself.                                                                                                                                                                                                                                              | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| many-PE chip, tile-based chip   | A chip built from many processing elements grouped in tiles.                                                                                                                                                                                                                                              | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| MLIR                            | A compiler framework for building toolchains that translate a model into code for a chip. Standard gloss; the project README names it.                                                                                                                                                                    | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| TPU                             | Tensor processing unit: Google's accelerator chip for models; the cloud service of an early VLA ran on several of them.                                                                                                                                                                                   | field | [RT-2](../resources/models/rt-2.md)                                  |
