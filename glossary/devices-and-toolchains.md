# Devices and toolchains

## Summary
The chips, memory types, kernel and graph words, toolchains, robot buses and chip terms the notes use. All terms are standard (scope field); the SoftHier chip terms come from the project README.

## Terms
| Term                               | Meaning                                                                                                                                                                                                                                                                                                   | Scope | Defined in                                                                                                                                                                                           |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Jetson Orin Nano, AGX Orin, Thor   | NVIDIA embedded GPU modules, from small to large; the sources measure most edge VLA runs on them.                                                                                                                                                                                                         | field | [edge hardware](../knowledge/edge-hardware-and-the-10-tops-gap.md)                                                                                                                                   |
| RK3588                             | A Rockchip chip with a built-in NPU, common in robot prototypes.                                                                                                                                                                                                                                          | field | [RK3588 deployment](../knowledge/rk3588-vla-deployment.md)                                                                                                                                           |
| Ascend, Hailo                      | Accelerator families from Huawei and from Hailo.                                                                                                                                                                                                                                                          | field | [edge hardware](../knowledge/edge-hardware-and-the-10-tops-gap.md)                                                                                                                                   |
| LPDDR, DRAM                        | DRAM is the main memory outside the chip, where a model's weights live; LPDDR is the low-power kind used in edge chips.                                                                                                                                                                                   | field | [RK3588 deployment](../knowledge/rk3588-vla-deployment.md)                                                                                                                                           |
| kernel, kernel fusion              | A kernel is one GPU operation launch; fusion combines several into one to cut overhead.                                                                                                                                                                                                                   | field | [inference workload characterization](../knowledge/inference-workload-characterization.md)                                                                                                           |
| kernel launch overhead             | The fixed time it takes to start each GPU operation; with many small operations it can add up to more than the arithmetic. CUDA graphs and kernel fusion reduce it.                                                                                                                                       | field | [inference workload characterization](../knowledge/inference-workload-characterization.md)                                                                                                           |
| CUDA graph                         | A recorded sequence of GPU launches that is replayed with little launch overhead.                                                                                                                                                                                                                         | field | [inference workload characterization](../knowledge/inference-workload-characterization.md)                                                                                                           |
| tensor core versus CUDA core       | On NVIDIA GPUs, tensor cores are units specialised for small matrix multiplies at low precision, and CUDA cores are the general arithmetic units. A kernel that uses tensor cores can be faster on the same data. Standard gloss.                                                                         | field | [quantization](../knowledge/quantization.md)                                                                                                                                                         |
| eager versus compiled execution    | Eager execution runs a model operation by operation as written and pays overhead for each; compiled execution first fuses and records the operations so that overhead is smaller.                                                                                                                         | field | [SmolVLA](../knowledge/smolvla.md)                                                                                                                                                                   |
| torch.compile                      | PyTorch's compiler: it turns a model into fused, optimized code. It is one of the compiled options in the comparisons. Standard gloss.                                                                                                                                                                    | field | [inference workload characterization](../knowledge/inference-workload-characterization.md)                                                                                                           |
| GEMM                               | Matrix-matrix multiply, the main operation of a model's layers.                                                                                                                                                                                                                                           | field | [inference workload characterization](../knowledge/inference-workload-characterization.md)                                                                                                           |
| tile                               | A block handled as a unit. Image tile: one crop of an image that is cut into several. GEMM tile: the block of the result matrix that one compute unit works on; tile quantization is the loss when the tiles do not divide evenly across the units. SoftHier tile: one tile of a tile-based many-PE chip. | field | [inference workload characterization](../knowledge/inference-workload-characterization.md), [SmolVLA](../knowledge/smolvla.md), [SoftHier and the project](../knowledge/softhier-and-the-project.md) |
| SM                                 | Streaming multiprocessor: one compute unit of an NVIDIA GPU.                                                                                                                                                                                                                                              | field | [inference workload characterization](../knowledge/inference-workload-characterization.md)                                                                                                           |
| ONNX, TensorRT, Triton             | A model exchange format; NVIDIA's inference compiler and runtime; a language for writing GPU kernels.                                                                                                                                                                                                     | field | [inference workload characterization](../knowledge/inference-workload-characterization.md)                                                                                                           |
| ONNX Runtime                       | A runtime that executes ONNX models; the notes use it as the reference against which a converted model is checked.                                                                                                                                                                                        | field | [RK3588 deployment](../knowledge/rk3588-vla-deployment.md)                                                                                                                                           |
| RKNN, RKLLM                        | Rockchip's toolchains for NPU graphs and for language models.                                                                                                                                                                                                                                             | field | [RK3588 deployment](../knowledge/rk3588-vla-deployment.md)                                                                                                                                           |
| DDS, EtherCAT, CAN-FD, TorchScript | Robot-compute terms: DDS is a publish-subscribe message bus between software parts; EtherCAT is a real-time network for joint controllers; CAN-FD is a field bus for short messages; TorchScript saves a PyTorch model as a program that runs without Python. Standard gloss except DDS.                  | field | [robot compute partitioning](../knowledge/robot-compute-partitioning.md)                                                                                                                             |
| PE (processing element)            | One small compute unit of a many-PE chip.                                                                                                                                                                                                                                                                 | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md)                                                                                                                                 |
| SRAM                               | Static random-access memory: fast memory on the chip itself.                                                                                                                                                                                                                                              | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md)                                                                                                                                 |
| many-PE chip, tile-based chip      | A chip built from many processing elements grouped in tiles.                                                                                                                                                                                                                                              | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md)                                                                                                                                 |
| MLIR                               | A compiler framework for building toolchains that translate a model into code for a chip. Standard gloss; the project README names it.                                                                                                                                                                    | field | [SoftHier and the project](../knowledge/softhier-and-the-project.md)                                                                                                                                 |
| A40, V100, H20, B100               | NVIDIA GPU models that appear as measurement hardware in the tables; the notes say no more about them than their names. Standard gloss.                                                                                                                                                                   | field | [XPU study](../resources/serving/vla-xpu-characterization.md)                                                                                                                                        |
| TPU                                | Tensor processing unit: Google's accelerator chip for models; the cloud service of an early VLA ran on several of them.                                                                                                                                                                                   | field | [RT-2](../resources/models/rt-2.md)                                                                                                                                                                  |
| OOM                                | Out of memory: the model's weights and working data do not fit in the device's memory, so the run fails; the notes report it for large models on small devices.                                                                                                                                           | field | [edge hardware](../knowledge/edge-hardware-and-the-10-tops-gap.md)                                                                                                                                   |
