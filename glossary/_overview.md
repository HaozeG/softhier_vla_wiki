# glossary/

Look terms up here while you read; you do not need to read it first. The best order for a newcomer is the README, then [one VLA call](../knowledge/one-vla-call.md), then the [VLA architecture overview](../knowledge/vla-architecture-overview.md), using this glossary for any word that is new. Terms of physical AI so far come mostly from VLA models.

**How to read the scopes.** Each file has a terms table (Term, Meaning, Scope, Defined in) and explanations below it.
- `field`: the standard meaning; you can trust it from general knowledge. A row marked "standard gloss" gives the general meaning because the linked note only uses the term.
- `convention`: this wiki's own use of a field term or symbol; trust the wiki, not general knowledge. Names of these terms are listed at the start of project sessions.
- `project`: defined by a SoftHier-VLA decision or the project README. Look up a definition with `tools/wiki.py glossary "<term>"` ([wiki-design decision 0012](../wiki-design/decisions/0012-glossary-with-on-demand-lookup.md)).
