# glossary/

Look terms up here while you read; you do not need to read it first. The best order for a newcomer is the README, then [one VLA call](../knowledge/one-vla-call.md), then the [overview](../knowledge/vla-edge-serving-overview.md), using this glossary for any word that is new. Terms of physical AI so far come mostly from VLA models.

**How to read the scopes.** Each file has a terms table (Term, Meaning, Scope, Defined in) and explanations below it.
- `field`: the standard meaning; you can trust it from general knowledge. A row marked "standard gloss" gives the general meaning because the linked note only uses the term.
- `convention`: this wiki's own use of a field term or symbol; trust the wiki, not general knowledge. Names of these terms are listed at the start of project sessions.
- `project`: defined by a SoftHier-VLA decision or the project README. Look up a definition with `tools/wiki.py glossary "<term>"` ([wiki-design decision 0012](../wiki-design/decisions/0012-glossary-with-on-demand-lookup.md)).

- [VLA](model-and-attention.md), [token](model-and-attention.md), [prefix](model-and-attention.md), [KV cache](model-and-attention.md)
- [action chunk](robot-and-control-loop.md), [control step](robot-and-control-loop.md), [latency](robot-and-control-loop.md)
- [flow matching](action-generation.md)
- [memory-bound and compute-bound](hardware-and-performance.md), [TOPS](hardware-and-performance.md)
