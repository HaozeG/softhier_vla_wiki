# SoftHier-VLA wiki

Top-level map. Start here, drill down via each directory's `.overview.md`.

- `resources/` — one faithful note per external source (papers, docs, repos), cited via `sources:`.
- `knowledge/` — synthesized concept/entity notes, cross-linked and revised as sources arrive.
- `memories/` — decisions and lessons. `memories/decisions/` holds numbered decision records.
- `skills/` — runbooks: ingesting a source, reviewing wiki health.

Change log: `tools/wiki.py log` (git). Health: `tools/wiki.py health`. Search: `tools/wiki.py find "..."`. Conventions: `CLAUDE.md`.
