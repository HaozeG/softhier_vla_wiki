# π0.5: a Vision-Language-Action Model with Open-World Generalization

Physical Intelligence (Black, Brown, Darpinian, et al.), arXiv 2504.16054 (Apr 2025).

## Summary
π0.5 extends π0 with co-training on heterogeneous data (multiple robots, web data, high-level subtask labels, verbal instructions) and a hierarchical inference procedure in which the same model first emits a text subtask and then low-level actions. It is trained in two stages: pretraining with discrete FAST action tokens, then post-training that adds a flow-matching action expert for real-time continuous actions. It performs 10–15 minute household tasks in unseen homes.

## Key claims
- **Two-stage recipe (§IV-B, §IV-D):** pretraining for 280k steps with all outputs as discrete tokens (text, boxes, FAST actions; α = 0), then 80k steps of post-training with joint next-token and flow-matching losses (α = 10) on an action expert initialized randomly. Attention masks prevent the two action representations from attending to each other.
- **Inference (§IV-B):** autoregressive decoding of the subtask text, then 10 denoising steps of the action expert conditioned on it. The action expert is the same size as π0's: Gemma 2B VLM (width 2048, depth 18) and a 300M expert (width 1024); the flow timestep enters through adaptive RMSNorm instead of being fused into the action token (App. E).
- **Data (§IV-C):** about 400 hours of mobile-manipulator data from about 100 homes plus non-mobile, cross-embodiment lab data, Open X-Embodiment, high-level subtask labels, and web captioning, VQA and detection data.
- **Control:** targets for arms, gripper, torso and base at 50 Hz with action chunking (chunk 50); 18–19 DoF; simple PD tracking.
- **Ablations (Fig. 10–12):** cross-embodiment data (ME, CE) matter most; web data matters mostly for out-of-distribution objects and high-level inference; π0.5 beats π0 and an enhanced π0-FAST+Flow.
- **Not in the paper:** on-device latency or hardware numbers; other papers in this wiki that serve π0.5 report them (for example [Jetson-PI](../serving/jetson-pi.md), [real-time chunking](../serving/real-time-chunking.md) uses 5 denoising steps).

## Relevance to SoftHier-VLA
π0.5 is the current reference open VLA and the base for most recent serving papers, but its inference has two phases: an autoregressive text decode (memory-bound, variable length) followed by the flow loop. See [VLA architecture overview](../../knowledge/vla-architecture-overview.md) and [inference workload characterization](../../knowledge/inference-workload-characterization.md).

Predecessor: [π0](pi0.md) (same layer dimensions; flow-only training, no subtask prediction, timestep fused into the action token). Related: [FAST](fast-tokenizer.md), [GR00T N1](gr00t-n1.md).
